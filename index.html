01 — EL PROYECTO

¿Qué es Espiga?

Una herramienta pensada para que la información del negocio esté organizada, actualizada y disponible desde un mismo lugar.

“Toda la información de PCR Amoblamientos, organizada en un solo lugar.”

El sistema busca centralizar la gestión cotidiana de un taller de muebles a medida: clientes con cuenta corriente, proveedores, pedidos, archivos técnicos, cobranzas y entregas.

ClientesConsulta y gestión de cuentas corrientes.
PedidosSeguimiento de estados y documentación.
PagosRegistro y consulta de saldos.
EntregasCalendario, alertas y seguimiento.
02 — EL PUNTO DE PARTIDA

El problema

La gestión de PCR Amoblamientos se realizaba de forma manual y dispersa, dificultando la consulta, el seguimiento y la trazabilidad de la información.

👤

Clientes

La información y los saldos podían requerir reconstrucción manual.

📋

Pedidos

Era necesario seguir cada pedido y conocer su estado.

💰

Cobranzas

La organización de pagos y pendientes necesitaba mayor centralización.

🚚

Entregas

Había que controlar fechas y anticipar entregas próximas.

03 — LA SOLUCIÓN

Todo conectado.

Espiga reúne en una misma plataforma las principales tareas de gestión del taller.

👥

Clientes y cuentas

Alta, consulta y gestión de clientes y sus cuentas corrientes.

📦

Pedidos

Creación y seguimiento de pedidos según su estado.

💳

Pagos

Registro de pagos, comprobantes y consulta de saldos.

🏭

Proveedores

Control de proveedores y seguimiento de deudas.

📐

Archivos técnicos

Planos, fotografías y listas de corte asociados a cada pedido.

📅

Entregas y alertas

Calendario y avisos para entregas próximas, además de recordatorios de cobranza.

04 — USUARIOS

Diseñado para cada rol.

Cada perfil accede a las herramientas necesarias para realizar sus tareas dentro del sistema.

01

Administrador

  • Gestiona usuarios.
  • Administra información general.
  • Accede a las funciones de gestión.
  • Gestiona copias de seguridad.
02

Administrativo

  • Gestiona clientes y cuentas corrientes.
  • Carga pedidos y archivos técnicos.
  • Registra pagos.
  • Genera comprobantes y resúmenes.
03

Operador

  • Actualiza estados de producción.
  • Consulta pedidos y calendario.
  • Recibe notificaciones.
  • Genera recordatorios de cobranza.

06 — TECNOLOGÍA

La parte que hace posible Espiga.

La solución combina una interfaz web, un backend para la lógica del sistema y una base de datos para organizar la información.

FRONTEND

HTML · CSS · JavaScript

Interfaz web para acceder y trabajar con el sistema.

BACKEND

Node.js + Express

Procesa las operaciones y reglas del sistema.

DATOS

MySQL

Base de datos relacional normalizada para almacenar la información.

PUBLICACIÓN

Railway

Sistema publicado en la nube y accesible desde distintos dispositivos.
